# Living Archive Labs site

    npm install
    npm run dev      # local preview
    npm run build    # outputs dist/ (upload to your host)

## Add your logos
Drop files into `src/assets/logos/` named exactly:
- `project-logo.png` (or .svg/.jpg/.webp), shown on Home (featured project) and Work
- `terentia-logo.png` (or .svg/.jpg/.webp), shown on Home (partner band) and Work

Placeholders disappear automatically once the files exist.

## Edit content
All text, projects, CV entries and links live in `src/data.js`.
